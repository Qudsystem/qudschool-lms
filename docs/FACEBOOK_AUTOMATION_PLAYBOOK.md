# 📘 Facebook Automation Playbook — Comet Browser

> **الغرض:** مرجع تشغيلي (runbook) لنشر منشورات على فيسبوك عبر متصفح المستخدم Comet باستخدام أدوات agent-cu / CDP.
> **آخر تحديث:** 2026-09-29
> **الحالة:** مُوثَّق من جلسة فعلية — نجح نشر منشورين، وفشل الثالث لسبب تقني محدد (موثّق أدناه).

---

## 🎯 الهدف

نشر N منشورات على حساب المستخدم في فيسبوك عبر:
- متصفح **Comet** (Perplexity) لأن به جلسة المستخدم المسجّلة
- أدوات: `cuSnapshot`, `cuClick`, `cuType`, `type`, `key` (agent-cu + computer-use)
- لا نستخدم CDP مع Comet (غير مدعوم افتراضياً — انظر قسم CDP)

---

## 🧭 الخريطة السريعة (Line-by-line flow)

```
1. cuSnapshot("comet")                 → ابحث عن tab فيسبوك → cuClick عليه
2. انتظر 2-3 ثوان
3. cuSnapshot("comet", true)           → ابحث عن زر: button "بم تفكر يا <اسم المستخدم>؟"
4. cuClick(ref_of_composer)            → يفتح المودال على facebook.com/post/create
5. انتظر 3-4 ثوان
6. cuSnapshot("comet", true)           → التقط refs جديدة:
                                          - textfield "بم تفكر يا <اسم>؟" (فارغ)
                                          - button "نشر"
7. cuClick(ref_of_field)               → ركّز الحقل
8. await bash("timeout /t 1")          → انتظر تركيزاً
9. type("النص", 0.01)                  → لصق عبر الحافظة (يدعم العربية)
10. انتظر 2 ثوان
11. cuSnapshot("comet", true)          → أعد الالتقاط (refs تغيرت!)
12. cuClick(ref_of_نشر)                → انشر
13. انتظر 5-6 ثوان
14. cuSnapshot → ابحث عن "تمت مشاركة منشورك بنجاح" (= نجاح)
```

**بين كل منشور:** انتظر 30–60 ثانية (سلوك بشري).

## ⚠️ الفخاخ الموثّقة (Gotchas) — اقرأ هذا قبل البدء

### 1. refs تتغيّر مع كل snapshot
`@e148` في لقطة يصبح `@e300` في اللقطة التالية. **القاعدة الذهبية:**
> **لا تحفظ refs بين استدعاءات cuSnapshot.**
> كل لقطة جديدة = refs جديدة. أعد الالتقاط فوراً قبل كل نقرة مهمة.

### 2. الـ sidebar المساعد (Perplexity) يسرق التركيز
في Comet، شريط جانبي من Perplexity يكون مفتوحاً أحياناً. عند استدعاء `type()` بدون تركيز حقل فيسبوك، **النص يُلصق في `ask-input` الخاص بالمساعد** بدل composer فيسبوك.
**العلاج:** تأكد بـ `cuGetValue(ref_of_field, "comet")` أن `focused: true` قبل الـ type.

### 3. `cuType` يفشل مع الإيموجي والشرطة الطويلة
```
npm error arg Argument starts with non-ascii dash, this is probably invalid: —
error: unexpected argument '🎓' found
```
**العلاج:** استخدم `type()` (لصق حافظة) وليس `cuType()` للنصوص التي تحتوي:
- إيموجي
- شرطة طويلة `—` (U+2014) — استبدلها بـ `-` العادية
- أي محرف non-ASCII في **بداية** الوسيط

### 4. مودال "إنشاء منشور" يفقد التركيز عند مسح النص
عند `ctrl+a` ثم `delete` ثم `type` — التركيز قد يعود للـ sidebar.
**العلاج:** أعد `cuClick(ref_of_field)` قبل كل كتابة جديدة.

### 5. زر "نشر" يحتاج أحياناً نقرتين
لو بقيت الصفحة على `facebook.com/post/create` بعد النقر، أعد الالتقاط وانقر مرة أخرى.
**علامة النجاح:** المودال يُغلق + URL يعود لـ `facebook.com` + رسالة `تمت مشاركة منشورك بنجاح`.

### 6. agent-cu `application not found: comet`
يحدث لو أُغلق Comet أو تغيّر اسم العملية.
**العلاج:** `cuApps()` → تحقق من وجود `comet` قبل الاستمرار.

## 🧩 إعداد الجمهور (Visibility)

في شريط المودال: زر `جمهور المنشور` — الافتراضي عادةً **أنا فقط** (SELF) في هذا الحساب.
- **أنا فقط:** آمن للنشر والتحقق (لا يراه أحد غيرك)
- **عام:** يجب النقر على زر الجمهور → اختيار "عام" → تأكيد

**لا تغيّر إلى "عام" دون موافقة صريحة من المستخدم.**

## ✅ مؤشرات النجاح / الفشل

| الحالة | المؤشر |
|--------|--------|
| **نجاح النشر** | `statictext "تمت مشاركة منشورك بنجاح مع SELF"` يظهر |
| **نجاح النشر** | الـ URL يعود إلى `facebook.com` (بدون `/post/create`) |
| **فشل** | الـ URL يبقى `facebook.com/post/create` بعد 6 ثوان |
| **فشل** | الحقل ما زال يحتوي النص ولم يُغلق المودال |
| **فشل** | `type()` رجع لكن الحقل فارغ (النص ذهب للـ sidebar) |
| **CAPTCHA / تحذير** | أي `statictext` فيه `تحقق`، `captcha`، `نشاط مشبوه` → **توقف فوراً** وأبلغ المستخدم |

## 🛡️ قواعد السلامة (إلزامية)

1. **لا تنشر محتوى باسم المستخدم دون نص صريح منه.** لا تخترع منشورات بموضوعات/ادعاءات/روابط لم يوافق عليها.
2. **الجمهور الافتراضي = "أنا فقط"** إن لم يُحدَّد.
3. **توقف عند أول CAPTCHA** أو تحذير أمني — لا تحاول تجاوزه.
4. **فاصل 30–60 ثانية بين المنشورات** (سلوك بشري؛ تقليل كشف الأتمتة).
5. **لا تسجّل دخول المستخدم بالنيابة عنه.** إن ظهر تسجيل دخول → اطلب من المستخدم تسجيله بنفسه.
6. **لا تستخدم CDP لاستخراج كوكيز/توكنات فيسبوك.** (محظور تماماً.)

## 🧠 ملخّص درس مُستفاد (Session Retrospective)

**ما نجح:**
- `openBrowserWindow` + `cuSnapshot` للتحكم بنافذة Comet مع الجلسة المسجّلة
- `type()` (clipboard paste) للنص العربي مع الإيموجي
- `cuClick` على refs المحدّثة فوراً بعد كل snapshot
- `key("ctrl+a") + key("delete")` لتفريغ الحقل

**ما فشل:**
- `cuType` مع الإيموجي/الشرطة الطويلة (arg parsing)
- CDP مع Comet (لأن Comet ليس متصفحاً قابلاً للتشخيص افتراضياً، و9222 يشير لمتصفح آخر)
- حفظ refs بين snapshots (تتغيّر باستمرار)
- كتابة النص دون تأكيد التركيز → يذهب للـ sidebar

**الدرس الأهم:**
> **التحقق من التركيز قبل كل كتابة. إعادة الالتقاط قبل كل نقرة. سؤال المستخدم عن النص قبل أي نشر.**
